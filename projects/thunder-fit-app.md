# THUNDER — Workout & Strength Tracker

**Categoria:** Desenvolvimento de Software · **Status:** Em desenvolvimento

O THUNDER é uma aplicação web/PWA voltada ao acompanhamento de treinos de força e à organização da rotina de exercícios. O projeto faz parte da minha prática de programação e evolução na construção de aplicações.

## Repositório

- [Código-fonte e documentação](https://github.com/thiagoalphabsb/THUNDER-FIT-APP)

## Tecnologias identificadas no repositório

- React e TypeScript
- Vite
- Firebase / Firestore
- Recursos de Progressive Web App (PWA)
- Componentes de interface para treinos, rotinas, histórico, progresso e descanso

## O que pretendo demonstrar

- Organização de uma aplicação frontend por componentes
- Modelagem de funcionalidades de acompanhamento de treinos
- Integração com serviços de backend
- Experiência de uso em dispositivos móveis
- Evolução incremental, testes manuais e documentação técnica

> Projeto pessoal em desenvolvimento. As funcionalidades e integrações devem ser consideradas sujeitas a alterações; a documentação não substitui a validação prática da versão publicada.

## Evidências visuais planejadas

As capturas de tela serão adicionadas depois da validação manual da versão atual. As imagens devem representar a interface real, sem dados pessoais, tokens, chaves ou informações sensíveis.
