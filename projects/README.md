# THUNDER — Workout & Strength Tracker

**Categoria:** Desenvolvimento de Software · **Status:** Em desenvolvimento

O **THUNDER** é uma aplicação web progressiva (PWA) desenvolvida para o acompanhamento completo de treinos de força, gestão de cargas, métricas de progresso e organização da rotina de exercícios. O projeto faz parte da minha prática de desenvolvimento de software e construção de aplicações web modernas.

---

## 🔗 Links e Repositório

- **Repositório do Código-Fonte:** [THUNDER-FIT-APP no GitHub](https://github.com/thiagoalphabsb/THUNDER-FIT-APP)

---

## 🛠️ Tecnologias Utilizadas

- **Frontend:** React, TypeScript, Vite
- **Estilização & UI:** Tailwind CSS, Lucide Icons, Design Responsivo (Mobile-First)
- **Backend & Database:** Firebase / Firestore (Sincronização em tempo real e persistência offline)
- **Recursos PWA:** Progressive Web App, suporte a instalação mobile e execução offline
- **Inteligência Artificial:** Integrado com Gemini AI (*Strength Coach*) para análise de volume e recuperação

---

## 🎯 Objetivos do Projeto

- **Arquitetura de Software:** Organização de aplicação frontend modularizada por componentes funcionais.
- **Engenharia de Usabilidade:** Interface intuitiva e fluida otimizada para uso em dispositivos móveis durante o treino.
- **Integração com Backend:** Persistência local e remota com Firebase Firestore e exportação/importação de dados em CSV/JSON.
- **Análise de Dados:** Visualização gráfica de volume semanal, histórico de cargas, recordes pessoais (PRs) e retrospectiva estilo *Wrapped*.
